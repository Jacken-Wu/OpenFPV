# OpenFPV

个人开发的开源穿越机探索游戏，采用 Godot 4 与 GDScript，方向为程序化世界、三维像素风、自由飞行和世界交互。

## 原型目标

能在一小片生成式世界里自由飞行，切换两套机型并在限定范围内调参，完成一次设施任务取得新装备，通过一个商店取得另一个配件，并在重新启动后恢复进度。地图系统通过三维分块和生成器接口，验证地表、空中与地下的扩展路径。

本阶段不接入商业地图服务，不依赖运行时大模型接口。尚未选定最终开源许可证，也未发布或推送远程仓库；开源发布前补齐代码与资产许可。
