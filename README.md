OpenFPV 是一款穿越机自由探索游戏。驾驶四旋翼穿行于城市、山谷、浮岛和地下迷宫，完成挑战、购买配件，调整自己的飞行手感。游戏没有电池、续航或燃料限制，可以尽情探索。

## 下载与开始

在 [Releases 页面](https://github.com/Jacken-Wu/OpenFPV/releases) 下载 Windows x64 版 `OpenFPV.exe`，双击运行。

> 游戏仍在测试阶段，目前尚无可下载的发行版本。

1. 连接 USB 遥控器，按 **F2** 选择设备并完成校准；也可以使用键盘体验。
2. 游戏开始时处于暂停状态。确认油门位置后，按 **P / 空格**开始飞行。
3. 先练习低油门起飞、转向和降落。需要重新开始时，按 **R** 回到传送点。
4. 按 **M** 查看地图，选择任务并领取；也可以直接飞到任务平台接取。

## 操作与飞行

### 常用按键

| 按键 | 功能 |
| --- | --- |
| P / 空格 | 暂停或恢复飞行 |
| E | 交互：接任务、登记传送点、打开服务；部分任务需要按住 |
| R | 重置到传送点 |
| M / F3 | 打开或关闭地图，F3 优先显示附近任务 |
| C | 切换第一人称与追逐视角 |
| F12 | 拍照 |
| Esc | 打开暂停菜单，或返回上一页 |
| F1 | 操作帮助与新世界入口 |
| F2 | 遥控器设置与校准 |
| / | 打开控制台，输入 `/help` 查看指令 |

失去焦点或遥控器断开时，游戏会自动暂停。重新连接后需要确认输入设备并主动恢复飞行。

### 键盘控制

| 按键 | 飞行动作 |
| --- | --- |
| W / S | 俯仰 |
| A / D | 横滚 |
| J / L | 偏航 |
| ↑ / ↓ | 增加 / 减少油门 |

键盘油门会保留当前值，松开按键不会自动归零。

游戏采用 **Acro 角速度控制**：摇杆决定机体旋转速度，回中后保持当前倾角，不会自动恢复水平。需要主动修正姿态；机体倾斜时，推力方向也会随之改变。

飞行高度超过 280 米时会出现警示，超过 300 米时电机停止输出，下降至 280 米后恢复。请提前控制高度，避免失去推力后撞击地形。

### 遥控器与操作预览

按 **F2** 分别选择遥控器配置和输入设备。新建配置后，按提示采集四轴行程，确认横滚、俯仰、偏航、油门的通道和正反方向，再保存使用。

- 为各轴设置死区，可以抑制遥控器漂移和抖动；油门死区作用在最低端。
- 辅助通道可绑定暂停、恢复、交互、重置、拍照或切换视角等动作。
- 配置支持编辑、改名和删除，便于切换不同遥控器。
- **Esc → 操作预览**可显示摇杆和拨杆状态，支持左右手油门布局，方便查看操作和录屏。

## 探索与传送

世界按种子生成，包含城市、松林、峡谷、高山、雪山、雪原、废城、巨构遗址、戈壁、火山，以及空中浮岛和地下迷宫等地区。可以钻过楼间通道、广告架和蜂窝岩，穿行山洞、竖井与多层廊道。

按 **M** 打开地图，用滚轮缩放、拖动平移，也可以切换高度层或定位无人机。已发现的地区会保留在地图中；地下迷宫需要完成测绘任务后揭示内部结构。

- **查看地点：** 点击图标或列表查看详情，不会更换当前导航。
- **追踪地点：** 选中地点后点击“追踪”。点击地图空白处可预览临时路标，再点“追踪”启用。
- **清除导航：** 点击“清除指引”，不会放弃已领取的任务。
- **解锁传送：** 飞到服务平台中央降落并停稳，按 **E** 登记，再从地图详情中传送。

传送后游戏保持暂停，待周围环境加载完成后再恢复飞行。失落废城需要先完成当地 **3 条修复线路**，才能使用传送点和服务平台。

导航点在视野内显示为圆点，超出画面或位于身后时显示方向箭头。地下路线会显示短程引导线和后续航点。导航不会自动避开所有障碍，仍需观察地形和建筑。

## 任务

每个地区通常有 **2～5 个任务**，可以在地图领取，也可以在任务接待平台中央降落、停稳后按 **E** 接取。

任务点的立体标签用颜色区分状态：青绿为未接取、金色为已接取、蓝灰为已完成，气球挑战失败时为红色。地图也可以筛选未完成、进行中和已完成任务。

| 类型 | 完成方式 |
| --- | --- |
| 巡检 / 校准 / 维修 | 到目标位置按提示交互或停留 |
| 快递 | 领取物品并运送到目标位置 |
| 勘测 | 完成地区测绘，揭示地图 |
| 摄影 | 满足距离、角度和遮挡要求后按 F12 |
| 立体穿门 | 按编号和方向依次穿过门框，无时间限制 |
| 扎气球 | 撞破全部气球，不能让任何一个超过限高 |
| 平面环绕 | 镜头对准目标，在指定范围内完成 360° 环绕 |
| 跟拍 | 拍摄至少 30 秒，目标在视野内和在 50 米范围内的时间分别达到 80% |
| 区域解密 | 完成废城修复线路、巨构顺序终端或无碰撞穿行 |

**立体穿门：** 领取并追踪后，金色引导线表示当前航段，青色表示后续航段，箭头指明前进方向。通过门框和到达终点都有声音提示。

**扎气球：** 在地图远程领取后，需要飞到接待平台停稳并按 **E** 启动；现场首次接取会直接开始准备。气球陆续放出并持续上升，任一越过限高则失败，返回平台可重试。

**运镜：** 环绕时短暂偏离或丢失目标只暂停进度，回到要求范围可继续；反向环绕会抵消进度。跟拍可以延长拍摄时间来提高两项达标比例。

**区域解密：** 修复线路需要依次靠近终端并按住 **E**；顺序终端需要按指定顺序激活；无碰撞穿行需要完成整条路线，碰撞或重置后重新开始本次挑战。

任务可以重复接取，**只有第一次完成时发放信用点或装备**。已获得的奖励和探索记录会保留。

## 装备与设置

在已开放的服务平台中央停稳，按 **E** 打开服务页面。商店按套机、机架、电机和桨叶分类，完成任务赚取信用点后即可购买。装配时需要满足配件兼容条件。

在“操控曲线”中可以调整各轴最大角速度、Expo 和 PID。建议从默认值开始，小幅调整后试飞；不满意时可恢复默认。

暂停菜单还提供以下设置：

- **声音：** 选择输出设备，分别调节主音量、电机、音效、快门和背景音乐。
- **操作预览：** 显示摇杆与拨杆状态。
- **探索成就：** 查看群系、传送点和任务类型等收集进度。
- **存档管理：** 保存、复制、改名和切换不同种子的世界。

发行版的存档、操控设置和照片保存在 `%APPDATA%/OpenFPV/Release/`。拍照后也会显示照片的实际路径，可以打开对应目录。

## 从源码构建

### 环境

- Windows x64、PowerShell、Git。
- [Godot 4.7.2 Standard](https://godotengine.org/download/archive/4.7.2-stable/)，以及对应版本的导出模板。

### 准备项目

克隆本仓库或自己的 fork，在项目根目录执行后续命令：

```powershell
git clone https://github.com/Jacken-Wu/OpenFPV.git
cd OpenFPV
```

设置 Godot 控制台程序路径，将示例路径替换为自己的安装位置：

```powershell
$env:GODOT_EXE = 'C:/Tools/Godot/Godot_v4.7.2-stable_win64_console.exe'
& $env:GODOT_EXE --headless --path game --editor --import
```

在 Godot 中安装匹配的导出模板后，运行：

```powershell
./tools/Setup-ExportTemplates.ps1
```

也可以使用 `./tools/Setup-ExportTemplates.ps1 -Download` 下载并准备模板。

### 构建

```powershell
# Debug
./tools/Build.ps1 -Configuration Debug

# Release
./tools/Build.ps1 -Configuration Release
```

输出分别位于 `builds/Debug/` 和 `builds/Release/`。
