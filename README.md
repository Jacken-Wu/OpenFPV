# OpenFPV

Godot 4 + GDScript 开发的穿越机探索游戏。P1 已可试玩：Acro 飞行、程序化块状世界、两套机型与有限改装、中继维修、商店及持久进度。没有电池、续航或消耗补给。

## 开始试玩

双击根目录 **Play.cmd**，或便携包 **builds/OpenFPV-P1/Play.cmd**。也可直接运行包内 OpenFPV.exe，无需打开编辑器。首次启动保持暂停。

1. 按 **F2** 选择 USB 加密狗。回中横滚、俯仰、偏航，油门最低，开始校准。
2. 一次只移动一根轴，完整往返，停在指定端点后记录。四轴完成后命名、保存。
3. 按 **P** 恢复，最低油门下按 **空格** 解锁，慢慢增加油门。初始机水平悬停油门约 41%，倾斜后需要更多推力。
4. 前往左侧终端，低速停留并按住 **E** 两秒；也可用 **M** 部署到终端平台体验交互。

Acro 松杆保持倾角，需要反向打杆回平。键盘适合查看世界和调试，精细手感请使用遥控器。

| 操作 | 按键 |
| --- | --- |
| 解锁 / 锁定 | 空格，解锁前油门低于 8% |
| 暂停 / 恢复 | P；失焦或断连会暂停并锁定 |
| 回到最近部署点 | R |
| 校准 / 选择输入 | F2 |
| 帮助 / 装备台 / 地图部署 | F1 / Tab / M |
| 维修 / 商店 | 按住 E 两秒 / E |
| 第一第三人称 / 拍照 | C / F12 |
| 键盘俯仰 / 横滚 / 偏航 | W S / A D / J L |
| 键盘调整油门 | ↑ ↓ |

## 已有内容

- 约 384 × 512 m 的两风格城市，外围按需生成峡谷；64 m 三维分块加载。
- 浮岛观测站和地下维修层可飞入，也可用 M 部署。它们是扩展技术样本，尚非完整群系。
- Explorer 5 初始套机；维修解锁 Light 3.5 和必要组件、200 信用点，并开启闸门。
- 商店花 150 点永久取得柔和桨叶。两机架、两电机组、三桨叶组和三动力映射来自资源清单。
- 装备台检查兼容和权限；相机角度、电机响应、桨叶校准有有限范围，落地锁定后应用。
- 移动货车供跟拍练习；F12 保存照片和复现信息。拍摄评分与回放尚未制作。

进度和配置在 `%APPDATA%/Godot/app_userdata/OpenFPV · 重连边境/`：profile 保存进度与备份，captures 保存照片及 JSON。重启恢复最近的安全部署点，不保存空中运动状态。

## 开发

基线 **4.7.2.stable.official.ed1daf0bf**，Compatibility，120 Hz 物理。

```powershell
./tools/Run.ps1 -Editor
./tools/Test.ps1 -Window
./tools/Build.ps1
```

引擎路径取自 GODOT_EXE、-GodotPath 参数或不提交的 .local/godot-path.txt。本机已经配置。测试使用隔离存档。

便携包附带完整 Godot 程序，约 173 MiB；标准精简 release 尚待安装匹配导出模板。实际 i6x 输入和手感、15 分钟人工飞行仍待用户验收，详见 [验证记录](docs/VALIDATION.md)。
