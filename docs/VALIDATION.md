# P1 验证记录

日期：2026-10-21。范围是本地原型，不表示真实遥控器或正式发行验收完成。

## 环境

Godot `4.7.2.stable.official.ed1daf0bf`，Windows x86_64，Compatibility / OpenGL 3.3，NVIDIA 驱动 610.47；i5-12600K、32 GB、RTX 4060 Ti。项目物理 120 Hz，后端设置返回 DEFAULT；未将其误写为特定物理后端名称。

## 自动检查

执行 `tools/Test.ps1 -Window`，导入、五个检查组、headless 场景和正常窗口巡检均通过。日志在 `.local/test-results/`，测试进度使用 `user://tests/` 隔离。

| 组 | 通过数量 | 覆盖重点 |
| --- | ---: | --- |
| input | 9 | 非对称中点、双轴同时满量程、非回中油门、反向、配置重复轴、即时油门解锁保护 |
| content | 18 | 目录引用、兼容、权限、范围/步长/NaN/无穷、资源只读、任务城市条件、幂等、购买、重启、损坏备份、写入失败 |
| world | 19 | 3D 负坐标、加载顺序、种子、城市边界、空岛顶侧底面、入口净空、地下地面、碰撞门槛、平移、部署切换 |
| flight | 9 | 悬停、三轴方向、Acro 不回平、锁定停转、落地、60 m/s 薄墙碰撞、套机和桨叶实际响应 |
| integration | 8 | 生产场景中实际按住 E、维修开门、奖励、购买、落地换机、重启、失焦与断连、地图 |

飞行固定条件示例：默认临时基准悬停一秒漂移 -0.0751 m；三款正式配置从静止全油门 300 ms 后垂直速度分别约 6.21 / 5.37 / 4.49 m/s。这些是回归检查，不是现实机型标定。

窗口巡检实际生成并查看城市、峡谷、浮岛、地下、装备台、校准和地图截图；同一路径还调用生产拍照功能，输出 PHOTO_CAPTURE_OK，并写入照片和复现 JSON。

## 打包

执行 `tools/Build.ps1`：导出资源包、提取引擎及组件许可、检查包内启动、对比源工程与资源包内容指纹。还直接运行 `builds/OpenFPV-P1/OpenFPV.exe` 验证自动识别同名 PCK，并执行正常显卡窗口巡检。

当前使用用户安装的完整 Godot 程序作为便携运行器，体积约 173 MiB；不是模板导出的精简 release。4.7.2 匹配模板未安装。

二进制资源转换路径曾在资源包中出现 PackedColorArray 越界，源工程和单独 ResourceSaver 往返正常。固定保留文本 Resource 后通过，目录校验也新增色板长度检查。此差异已附证据记录于项目记忆，不能从编辑器运行成功推断资源包成功。

## 1080p 脚本加载巡检

原始数据：[p1-1080p-streaming.json](benchmarks/p1-1080p-streaming.json)。种子 271828，1920 × 1080，120 秒，单独图形进程；使用单调时钟逐帧间隔，不使用平滑后的游戏 delta。

| 指标 | 结果 |
| --- | ---: |
| 帧数 | 11993 |
| P50 / P95 / P99 | 10.004 / 10.223 / 10.470 ms |
| 最长一帧 | 20.412 ms |
| 引擎静态内存峰值 / 结束 | 64.13 / 63.29 MiB |
| 节点峰值 / 结束 | 1227 / 1072 |

路线每三秒部署到城市、空岛、地下、峡谷和正负 1200 m 区域，包含卸载与原点平移。累计 399 帧等待碰撞准备；部署时机体保持冻结，未让未就绪区域变成可穿透区域。内存数值仅为引擎静态分配监视值，不含全部进程或显存。

这项检查证明短时加载压力下的帧时间与资源回落，不代替 15 分钟人工飞行、输入延迟或长期内存稳定性验收，也不声称每一帧都达到 60 fps。
